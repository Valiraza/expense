# Personal Expense Tracker

Application de suivi des dépenses personnelles avec MongoDB, Node.js/Express, et React/Tailwind.

## Installation

### Backend

```bash
cd backend
npm install
# Créez le fichier .env en vous basant sur .env.example
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

## Fonctionnalités

*   Authentification JWT
*   Gestion des dépenses et revenus
*   Dashboard avec statistiques
*   Gestion des budgets

## Technologies

*   MongoDB, Mongoose
*   Node.js, Express, TypeScript
*   React, Tailwind CSS, Recharts
